# Formulário com React e TypeScript

Este projeto é um **formulário desenvolvido em React com TypeScript**, com o objetivo de praticar conceitos de **componentização, tipagem estática e manipulação de formulários**.  

O projeto permite a entrada de dados do usuário, validação básica e exibição das informações preenchidas.
